# Code of conduct

This project follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good faith, no harassment of any kind. Report a problem privately through
GitHub's private vulnerability reporting on this repository (Security tab), marked "conduct". Maintainers will
answer within 5 working days and keep reports confidential.
